compression and texture decoding dependencies.
Their license texts are included in `_internal` with their package
metadata and the `licenses/` directory. PyInstaller builds the executable;
its bootloader is distributed under GPL with the bootloader exception.
The PyInstaller license is included in its bundled package metadata.

The application uses the user's installed browser. pywebview and Microsoft
Edge WebView2 Runtime are not used.

project artwork. Game assets, Mod previews and user cards are not distributed  
as part of this project.
